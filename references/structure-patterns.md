## 模板 1：AI 工具/技术分享型（五段式）

**来源**：architecture-diagram-generator 文章拆解

**叙事线**：痛点引入 → 效果震撼 → 原理解析 → 实操指南 → 价值升华

### 逐段拆解

**1. 开篇：直击痛点 + 解决方案**
- 公式：[行业普遍难题] + [传统方案的繁琐] + [引出新工具/新方法]
- 示例："做技术这行，总有些事是真心懒得做的，画架构图算一个……要么拖组件，要么写 Mermaid，效果还差。最近发现一个 Skill 把这件事解决了，效果出乎意料地好。"

**2. 主体第一部分：视觉冲击（Show, don't tell）**
- 公式：放效果图（图片/截图）+ 核心参数/配置清单（代码块或列表）
- 技巧：让读者一眼看懂"输入是什么"和"输出是什么"

**3. 主体第二部分：原理拆解（建立信任）**
- 公式：工具来源 + 底层机制 + 设计细节亮点
- 技巧：列举"语义色彩分层"、"箭头渲染顺序"等只有内行才懂的细节，拉高可信度

**4. 主体第三部分：保姆级实操（降低门槛）**
- 公式：安装方式（多种）+ 使用场景（基础 & 进阶）
- 技巧：照顾不同水平的读者，基础给 Prompt 模板，进阶强调迭代能力

**5. 结尾：价值总结 + Call to Action**
- 公式：总结收益（省时/高效）+ 给出链接
- 示例："1 分钟内能出一张质量不错的图……值得试一下。"附上 GitHub 仓库地址。

## 模板 4：系统指南/最佳实践型（九段式）

**来源**：OpenCode + oh-my-opencode 最佳实践指南拆解（玄熵智能，2026-05）

**叙事线**：读者定位 → 是什么 → 安装 → 核心概念 → 操作指南 → 扩展能力 → 场景实战 → 配置速查 → FAQ

**适用场景**：系统性介绍一个工具/框架/方法论，目标读者有相关经验但对该主题不熟悉。

### 逐段拆解

**0. 引言 blockquote：读者画像 + 文章边界**
- 公式：`> 面向 [目标读者]，聚焦 [文章定位]，基于 [信息来源]`
- 示例：`> 面向有 AI 编程助手使用经验的开发者，聚焦实战，基于官方最新文档（2026-04）整理。`
- 技巧：一句话告诉读者"这篇文章写给谁看的，你能学到什么"

**1. 一、是什么：一句话定义 + 核心差异**
- 公式：[一句话定义] + [配图/截图] + [与竞品/替代方案的核心区别（加粗）]
- 示例："与 Claude Code 最大区别：__不锁定模型，完全开源，Agent 体系可深度扩展。__"

**2. 二、安装与配置：多种方式并列**
- 公式：3种安装方式 + 推荐标注 + 配置步骤
- 技巧：用代码块展示，注释说明每种方式的特点

**3. 三、核心概念：概念先行（最关键章节）**
- 公式：先声明"这是理解 XX 的关键" → 分小节讲解核心概念 → 每个概念配表格/代码示例
- 技巧：概念讲透了，后面的操作章节才能写得简短。表格密集排列对比项。

**4. 四、基础操作：按场景分组**
- 公式：初始化 → 执行命令 → 撤销重做 → 上下文管理 → 其他
- 技巧：每组操作用二级标题，命令用代码块，注意事项用 blockquote

**5. 五、扩展/进阶：配置 + 自定义**
- 公式：配置文件位置（表格） → 配置示例 → 自定义Agent → 自定义命令
- 技巧：给出完整的配置文件示例，用 frontmatter 代码块

**6. 六、核心卖点/插件：深入挖掘价值**
- 公式：核心能力概述 → 安装验证 → 关键词/核心用法 → 专业组件列表（表格）
- 技巧：提炼一个"最重要的一个词/概念"重点推广

**7. 七、场景实战：按复杂度分级（干货密度最高的章节）**
- 公式：7+ 个场景，从简单到复杂，每个场景给完整代码/命令
- 技巧：同类型场景按 小/中/大 三级展示不同复杂度的用法
- 示例："小功能（1-2个文件）：直接 Build Agent" / "中等功能（多文件联动）：Plan → Build" / "大型功能（跨模块）：ulw 或 /start-work"

**8. 八、配置速查：JSON 配置示例**
- 公式：主要配置文件（代码块）+ 子配置文件（代码块）+ 内置能力表格
- 技巧：读者可以直接复制的配置

**9. 九、FAQ：预判读者疑惑**
- 公式：5-8 个 Q&A，每条简洁直接
- 技巧：选择读者看完前面章节最可能还困惑的点（如相似概念区分、中断恢复、上下文管理）
- 示例："Q：@ 引用文件和 @mention Agent 如何区分？"

**10. 参考资料**
- 公式：官方文档链接列表 + 社区资源
