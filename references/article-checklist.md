## AI 技术分享型文章 Checklist

**来源**：architecture-diagram-generator 文章拆解

### 开篇
- [ ] 是否描述了一个具体的、让人头疼的场景？
- [ ] 是否在 2-3 句内引出了解决方案？

### 展示
- [ ] 是否放了高清的效果图/视频？
- [ ] 图片下方是否有结构化的解释（不是"看图"两个字）？

### 解析
- [ ] 是否解释了工具背后的原理（哪怕只是简单提一下设计系统）？
- [ ] 是否有"内行才懂"的细节来建立信任？

### 实操
- [ ] 是否提供了可直接复制的安装命令或 Prompt？
- [ ] 是否照顾了不同水平的读者（基础 & 进阶）？

### 细节
- [ ] 是否提到了字体、配色、交互等"体验层"的细节？
- [ ] 代码/命令是否完整可执行（不是截断的片段）？

### 结尾
- [ ] 是否给出了项目的 GitHub 链接或官网？
- [ ] 是否有一句真诚的价值总结（不是假谦虚）？

## 技术教程/系统指南型文章 Checklist

**来源**：OpenCode + oh-my-opencode 最佳实践指南拆解（玄熵智能，2026-05）

### 标题与引言
- [ ] 标题是否为"工具名 + 文章类型"格式（如"XX 最佳实践指南"）？
- [ ] 是否用 blockquote 说明了目标读者和文章边界？
- [ ] 引言是否标注了信息来源和时效性（如"基于官方最新文档 2026-04"）？

### 结构与概念
- [ ] 是否先讲了"是什么"（一句话定义 + 核心差异）？
- [ ] 是否遵循概念先行原则（先讲核心概念再讲操作）？
- [ ] 概念章节是否有明确的声明引导（如"这是理解 XX 的关键"）？
- [ ] 是否提炼了一个"最重要的一个词/概念"作为抓手？

### 安装与配置
- [ ] 是否提供了多种安装/配置方式并标注推荐？
- [ ] 是否附了完整的配置文件示例（可直接复制）？

### 内容呈现
- [ ] 并列选项是否用表格而非段落罗列？
- [ ] 场景是否按复杂度分级（小/中/大）？
- [ ] 多种用法时是否提供了决策引导表？
- [ ] 关键易错点是否用 ⚠️ + blockquote 标注？
- [ ] 代码/命令是否完整可执行（不是截断片段）？
- [ ] 关键术语首次出现是否加粗？

### 实战场景
- [ ] 是否有独立的"场景实战"章节？
- [ ] 每个场景是否给出了可直接复制使用的命令/代码？
- [ ] 场景是否从简单到复杂排列？

### 收尾
- [ ] 是否有 FAQ 章节预判读者常见困惑？
- [ ] 是否附了官方文档/参考资料链接？
- [ ] 配置速查是否放在场景之后（先理解再配置）？
